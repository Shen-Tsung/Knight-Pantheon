# Knight-Pantheon

Это фан игра по Дельтаруне, где вы будете играть только за криса и путешествовать по разным мирам, встречаясь со знакомыми персонажами, а некоторым даже можно бросить вызов.

В данный момент в игре есть почти полностью функциональное меню, локация с двумя комнатами, и комната где тестируется битва с врагом. Реализовано взаимодействие с декором в первой комнате и персонажем во второй комнате.

Это первый проект, над которым я взялся всерьёз и который выглядит играбельно. Игра находится на самом дне разработки, где я пока ещё пишу фундамент и базовые механики для игры. То что находится сейчас в игре, просто моя песочница, где я тестирую и набираюсь опыта. Этот контент врядли войдёт в конечную версию.
